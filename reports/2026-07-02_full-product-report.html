1What PRISE is

The problem. Protein aggregation (amyloid formation) is measured by kinetic assays — most commonly Thioflavin-T (ThT) fluorescence rising over time as fibrils form. Thousands of such curves sit in the public CPAD 2.0 database, but they are heterogeneous, noisy, censored, digitised from figures, and stripped of much experimental metadata. The scientific questions — what is the aggregation regime? how fast? which nucleation mechanism? how does it scale with concentration? how aggregation-prone is this protein? — are routinely over-answered in the literature relative to what the data actually support.

PRISE's thesis. Build a computational framework that fits candidate models, compares them, classifies the aggregation regime, computes a propensity score, extracts curve characteristics — and, above all, refuses to claim more than the data license, reporting the boundary between the inferable and the unknowable. It is a pure analytical core: it ingests a frozen snapshot of CPAD 2.0 (and PDB structure links) at build time and performs no live database calls at run time.

The through-line: honesty over false precision

Every module is built so that a refusal is a first-class output. PRISE reports censoring as inequalities, refuses to name a mechanism it cannot license (0 licensed corpus-wide — see M5), demotes the scaling exponent γ to a constraint, gives finite-sample coverage guarantees instead of over-tight bootstrap intervals, and stamps every result with an engine_build_id that gates comparability. It has now also been checked, blind, against published consensus on field-resolved proteins (§4.15).

3The data foundation — CPAD 2.0

PRISE bundles a frozen, version-hashed snapshot of the Curated Protein Aggregation Database (CPAD 2.0) (Rawat, Prabakaran et al., Amyloid 2020) in two layers, joined by UniProt ID:

Kinetics layer

1,654 time-resolved aggregation curves across 105 proteins (81,484 usable (time, intensity) points), of which 1,526 have ≥6 points. 52 concentration-series groups span 34 proteins. Every value is a curator's graph digitisation of a published figure — so PRISE carries a per-point digitisation-uncertainty flag throughout.

Sequence & structure layer

Per-UniProt aggregation predictors (TANGO, AGGRESCAN, PASTA 2.0, Waltz-DB amyloid-hexapeptide coverage), curated aggregation-prone regions (APRs), and amyloid structures (PDB cross-refs). 382 UniProts, 231 with WT predictor reductions, 267 with APRs, 74 with structures.

Data-residency constraint (design-shaping)

CPAD bulk data is attribution-gated and not redistributable. PRISE therefore serves only derived analytical results and single curves for plotting (with attribution) — never a bulk-download endpoint. The corpus is .gitignored; all data/processed/* artifacts are regenerable from the ETL.

4The pipeline & the mathematics

Each module is a pure function (data in → JSON-serialisable data out), versioned, deterministic under a fixed seed. The engine is a directed pipeline; below, each stage is described with the mathematics it actually implements.

4.1 · M1 — Ingestion, artifact gate & censoring m1-triage-1.0

M1 triages each curve with scale-robust heuristics (CPAD intensities are a.u. with unknown normalisation, so decisions use each curve's own dynamic range and point-to-point noise). It emits:

  • fittability_class ∈ {fittable, suspect, unfittable} + reasons.
  • censoring_class ∈ {none, left, right, left_right, interval}. Right = still rising at the end (no plateau) ⇒ \(t_{50}\) is a lower bound and min–max normalisation is invalid; left = no lag phase at \(t_0\) (curve underway) ⇒ lag undefined, \(t_{50}\) biased early.
  • normalization discipline: baseline subtraction always; min–max only when a plateau is validated (never manufacture a plateau on a right-censored curve).

Calibrated thresholds (governed apply, thresholds-1.0)

M1's lag-slope fraction was applied at its Service-C held-out-validated value 0.45 (was a first-pass 0.30). This corrected an over-flagging of "left/no-lag": left-censoring dropped 711 → 607 curves. The previous value is retained; the change is dated, reversible, and bumps engine_build_id.

4.2 · M2 — Model-fitting bank m2-fitbank-1.0

Bounded, multi-start least-squares (scipy TRF) of a licensed bank of models. Per fit it reports SSE, \(R^2\), and the information criteria. For a Gaussian error model with \(n\) points and \(p\) parameters, with \(\hat\sigma^2 = \mathrm{SSE}/n\):

$$\ln\hat L = -\tfrac{n}{2}\big(\ln 2\pi + \ln\hat\sigma^2 + 1\big),\qquad \mathrm{AIC}=2p-2\ln\hat L,\qquad \mathrm{AICc}=\mathrm{AIC}+\frac{2p(p+1)}{n-p-1}.$$

The Akaike weight of model \(i\) (its posterior model probability under a uniform prior) is

$$\Delta_i=\mathrm{AICc}_i-\min_j\mathrm{AICc}_j,\qquad w_i=\frac{e^{-\Delta_i/2}}{\sum_j e^{-\Delta_j/2}}.$$

4.3 · M3 — Selection & identifiability (bootstrap-enveloped) m3-select-1.0

Model selection runs inside the bootstrap (honest post-selection inference): each wild (Mammen) resample \(y^\star_i=\hat y_i+r_i\,\varepsilon_i\) (with two-point weights \(\varepsilon\), \(E\varepsilon=0,\ \mathrm{Var}\,\varepsilon=1\), preserving heteroscedasticity) re-fits the candidates and re-selects. PRISE reports selection-stability frequencies — how often each model wins — rather than pretending the winner was known. A cross-model predictive interval is emitted only for the transferable functional \(t_{50}\), with a multimodality flag.

Practical identifiability. For the winning model, PRISE forms the column-normalised sensitivity (Jacobian) matrix \(\tilde J\) (\(\tilde J_{\cdot j}=\partial f/\partial\theta_j\) scaled to unit norm) and reports the collinearity condition number \(\kappa=\lambda_\max/\lambda_\min\) of \(\tilde J^\top\tilde J\); the eigenvector of \(\lambda_\min\) is the sloppiest (least-constrained) direction.

Honest relabel: this statistic is a sensitivity-collinearity condition number, not the Fisher-information parameter covariance. It detects practical non-identifiability. The true observed FIM lives in the global ODE fit (§4.5). The calibrated cutoff is \(\kappa>107\) (Service-C held-out; was 1000).

Now run on all 1,240 fittable curves (previously a 50-curve demonstration sample).

4.4 · M4 — Feature extractor & dual-γ m4-defs-1.0

Features are read off the selected model on a dense grid, under a versioned definition contract (a Gompertz \(t_{50}\) and a tangent-intercept lag from two different definitions are not comparable). Key definitions:

  • \(t_{50}\): first time the fitted signal reaches \(y_\min+0.5(y_\max-y_\min)\) — tagged point / lower-bound / biased-early by censoring.
  • Tangent-intercept lag: \(\ \tau_{\text{lag}}=t_\text{infl}-\dfrac{y_\text{infl}-y_\min}{\dot y_\max}\ \) (max-slope tangent's crossing of the baseline). Returned None for non-cooperative shapes (no interior inflection) — never an arbitrary argmax.
  • lag-to-\(t_{50}\) ratio \(=\tau_{\text{lag}}/t_{50}\) — a dimensionless shape invariant; a rare single-curve mechanistic signal (median ≈ 0.71 across cooperative curves).

Dual-γ — the headline mechanistic constraint

The half-time scaling exponent \(\gamma\) is defined by \(t_{50}\propto[m]^{-\gamma}\), i.e. \(\log t_{50}=c-\gamma\log[m]\). PRISE computes it two independent ways and never merges them:

  • \(\gamma_\text{regression}\) — a censored log–log ML regression. Uncensored points contribute a Gaussian density; a right-censored \(t_{50}\) contributes the inequality \(P(Y\ge \text{bound})=1-\Phi\!\big(\tfrac{\text{bound}-\mu}{\sigma}\big)\). Ships with a curvature test (concentration-dependent reaction order), an informative-censoring test, and an m_crit identifiability diagnostic.
  • \(\gamma_\text{collapse}\) — a phenomenological master-curve collapse coupling all member curves through one shared logistic shape + one \(\gamma\) (free per-curve amplitude). Explicitly not a shared-rate ODE fit (method="master_curve_collapse").

Two honesty gates that fire on real data

Negative-γ gate: a fitted \(\gamma<0\) (\(t_{50}\) rising with concentration — non-physical) is flagged gamma_physical=false and never emitted as a clean estimate (10 real series gated). Disagreement test: always reports the raw \(|\gamma_\text{reg}-\gamma_\text{collapse}|\) and a collapse-quality gate (collapse_r2<0.8 ⇒ shape not concentration-invariant) — 12 series now flagged disagreeing (a prior version suppressed all but 2).

4.5 · Global Knowles/Cohen ODE fit global-fit-1.0

The real shared-rate mechanistic fit. All member curves of a concentration series are fit simultaneously with shared microscopic parameters, only the monomer concentration varying per curve. The moment (mass/number) equations are

$$\frac{dP}{dt}=k_n\,m^{n_c}+k_2\,m^{n_2}\,\frac{M}{1+m^{n_2}/K_M}+k_-M,\qquad \frac{dM}{dt}=2k_+\,m\,P,\qquad m=m_\text{tot}-M,$$

where \(P\) is fibril number, \(M\) fibril mass, \(k_n,k_+,k_2,k_-\) the primary-nucleation, elongation, secondary-nucleation and depolymerisation rates, and \(n_c,n_2\) the reaction orders. Crucially PRISE estimates \(n_c,n_2\) (they are hard-fixed at 2 everywhere else) and reports the observed FIM \(\ \mathcal I=J^\top\Sigma^{-1}J\ \) eigendecomposition to identify which combinations of rates are constrained. From the fitted orders it derives an analytic third \(\gamma_\text{mechanistic}\) (e.g. \(\gamma=(n_2+1)/2\) for a secondary-nucleation-dominated half-time), a consistency cross-check on the two phenomenological \(\gamma\)s.

Honest performance limit

The corpus-scale global ODE fit is inherently too slow to run routinely — a single 62-curve series requires integrating 62 stiff ODEs per residual evaluation × multi-start × least-squares iterations, and did not finish even on three series. It is a build-time-only enrichment; dual_gamma joins its output where present. This is a compute reality, not a defect: the honest finding it delivers is that this corpus generally cannot pin unique microscopic rates (heavy sloppiness), only reaction-order constraints.

4.6 · M5 — Classification & regime registry m5-regimes-1.0

Three outputs against a declarative, versioned regime registry:

  1. Descriptive regime (always available, pure shape): cooperative_sigmoidal / gradual_non_cooperative / threshold_driven / non_monotonic_settling / no_detectable_aggregation / anomalous_unclassified.
  2. Mechanistic verdict → equivalence class. M5 never names a single mechanism. It returns the equivalence class and every gate it failed: assay-licensed (mass-proportional ThT/ThS only), shape-gated (γ a consistency check only), hard-branched on agitation & seeding (quiescent vs shaken are different mechanisms), and data-regime-conditional in its degeneracy.
  3. Confidence + rationale + condition vector + window of validity.

Plus a model-agnostic anomaly detector: a Wald–Wolfowitz runs test on the best-fit residual signs (few runs ⇒ systematic misfit), controlled corpus-wide by Benjamini–Hochberg FDR (reject \(p_{(k)}\le \tfrac{k}{m}\alpha\) for the largest such \(k\)), with a material-misfit effect-size gate (\(R^2<0.9\)) before anything becomes a human-triage registry proposal. The registry is human-governed; M5 never mutates it.

Why 0 mechanisms are licensed corpus-wide: agitation and seeding are unrecorded for essentially every CPAD curve, so the quiescent-vs-shaken hard branch is undetermined and the mechanistic gate refuses. This is the correct, data-earned result — and it is the crux of the M8 reachability finding.

4.7 · M6 — Propensity scorer & sequence axis m6-anchor-1.0 · m6-refscale-1.0

Propensity is reported in three views, never collapsed into one number:

  • surface — feature-vs-driving-force + the two γ's (primary where a series exists).
  • intrinsic — a leakage-free corpus anchor (the query protein excluded from its own condition/assay-matched stratum) when effective \(n\ge8\), else a versioned reference scale. Position uses the Hazen mid-rank plotting position \(\ \text{pct}=100\cdot(\#\text{below}+0.5\,\#\text{equal})/N\ \), and a sign-corrected propensity percentile (low \(t_{50}\) = high propensity).
  • cohort — rank/percentile within the analysis cohort, suppressed for singletons; amplitude/a.u. features are barred (only time-domain features are portable).

Sequence axis (de-conflated). TANGO / AGGRESCAN / PASTA / Waltz are separate named sub-axes with granularity, endpoint, version and an explicit per-predictor reduction. Only PASTA & Waltz are amyloid-specific; TANGO & AGGRESCAN are generic β-aggregation. A sequence-vs-kinetics comparison is licensed only on endpoint match — vs an amyloid dye (ThT/ThS/Congo Red/Cytofluor) only PASTA/Waltz are licensed; an unknown assay licenses nothing. Zyggregator/CamSol are declared absent; NuAPRpred declared intentionally excluded. Structure linkage (PDB/APR) is associative only, with a fibril-polymorphism caveat, never causal.

4.8 · Empirical-Bayes partial pooling pooling-1.0

The §4 hierarchical spine, deterministic (no MCMC). For a feature \(\theta\) with per-curve estimate \(\hat\theta_i\) and sampling variance \(s_i^2\), within a condition+assay-matched stratum, PRISE fits the two-level Gaussian \(\theta_i\sim N(\mu,\tau^2),\ \hat\theta_i\sim N(\theta_i,s_i^2)\), estimates \(\tau^2\) by DerSimonian–Laird, and shrinks:

$$\hat\theta_i^{\text{pooled}}=w_i\hat\theta_i+(1-w_i)\mu,\qquad w_i=\frac{\tau^2}{\tau^2+s_i^2}.$$

The weight is an explicit, frozen, versioned monotone function of \(s_i^2/\tau^2\). Noisy single curves in well-populated strata shrink hard toward the stratum mean; precise estimates barely move. Real corpus: 257 curves shrunk across 154 strata, 60 replicate groups (e.g. an Aβ40 outlier \(t_{50}\) of 37.6 h shrinks to 6.1 h at weight 0.21). Replicate groups additionally get a DerSimonian–Laird random-effects meta-analysis, retaining between-replicate \(t_{50}\) scatter as a stochastic-nucleation signal.

4.9 · M7 — Output assembler & build-id m7-assembler-1.0

Assembles one ProteinAnalysisResult per curve (no new inference) with a sortable information-yield ladder: mechanistic > scaling > descriptive > signal_only > uninformative. scaling requires a significant γ (reliable and 95% CI excludes 0), so a reliable-but-CI-spans-zero γ falls to descriptive. A degenerate-case contract emits a compact result (regime + yield + one ranked M9 hook + ≤3 impact-ranked caveats) for the low tiers — not a caveat avalanche. It carries no manufactured certainty (mechanistic.confidence null when unlicensed; construct-mismatch refuses the propensity).

The engine_build_id is a deterministic hash over every comparability axis — M1–M7 versions + anchor + reference scale + ETL schemas + a corpus_version folding every CPAD source digest + harness + env + thresholds_version. comparable(a,b) gates cross-build comparison on equality. Applying the calibrated thresholds bumped it bc442463dfdf → e660cb452b41, correctly marking prior results non-comparable.

4.10 · M8 — Inferential reachability map m8-reachability-1.0

A consolidation (no new inference) into a falsifiable map of what is inferable from CPAD, and what is not, under a mandatory validity ceiling: all counts are upper bounds on reachability / lower bounds on degeneracy, conditional on forward-model adequacy. The headline is the mechanistically-resolvable boundary:

33 proteins / 48 series are structurally resolvable (≥3-concentration, mass-assay families that a γ-resolved series could discriminate) — but 0 are actually licensed. The entire GAP of 33 is closed by a single metadata fix: recording agitation & seeding.

It also emits the inference ladder (of 1,654 curves: signal-present 1,606 → fittable 1,240 → descriptive 1,211 → scaling ~59 → mechanistic 0), an impact-ranked blocker census, and a data-richness × condition-completeness grid.

4.11 · M9 — Experimental-design recommender m9-recommender-1.0

Committed method: a Service-C-distilled rule table whose gains are quantified by Service C's measured degeneracy reduction (a γ-resolved series splits the Tier-B mechanism class 1 → 4 — a measured ~4× resolution). The full EIG/optimal-design computation is explicitly deferred. Candidates are ranked by reduction ÷ cost; the crediting is dependency-honest — recording agitation/seeding earns the full mechanism-unblock only where a concentration series already exists; on single-curve units it is discounted and flagged necessary-but-not-sufficient. Corpus headline: recording agitation & seeding is the cheapest action that closes the M8 GAP.

4.13 · Conformal prediction conformal-1.0

Distribution-free, finite-sample-valid intervals — stronger than the asymptotic bootstrap CIs. Split conformal on Service C's synthetic ground truth: nonconformity score \(s=|\hat t_{50}-t_{50}^{\text{true}}|\); the prediction interval is \(\hat t_{50}\pm q\) where \(q\) is the \(\lceil(n+1)(1-\alpha)\rceil/n\) empirical quantile of calibration scores, guaranteeing marginal coverage \(\ge1-\alpha\). It is Mondrian (a separate quantile per censoring/assay/regime stratum), one-sided for right-censored \(t_{50}\), and yields conformal prediction sets for the regime. Validated realized coverage at target 0.90: \(t_{50}\) 0.974, regime ~0.92 (Mondrian strata tighter — clean cooperative ±3 h vs ±8 h marginal).

Honest calibration caveat: coverage is guaranteed against the synthetic forward model (the only source with known \(t_{50}\)); real-CPAD validity holds insofar as the pre-registered noise model matches digitised traces — a stated, testable assumption.

4.14 · Service C — validation & identifiability engine service-c-1.0

The de-circularised synthetic backbone. It generates curves from a known ground truth (closed-form or Tier-B ODE + pre-registered ThT noise / drift / digitisation / censoring), runs the real engine on them, and measures recovery. It delivers parameter-recovery bias/RMSE/coverage; data-regime confusion matrices that genuinely test the K2 claim (a single curve collapses the four Tier-B mechanisms to one class; a γ-resolved series splits them into four); calibration (ECE 0.033 / Brier 0.063 on the descriptive confidence); an FDR-null with a power arm (realized FDP 0.0 and power 0.98 — control is only claimed with demonstrated power); held-out threshold recommendations (train-chosen, out-of-sample AUC — the values now applied in §4.1/§4.3); and a de-circularisation metric — the mechanism-misidentification degradation when the generating model ≠ the fitting model (≈ 0.53–0.67), reported on the calibration itself.

Stamped caveat: the "a concentration series splits all four mechanisms" result is partly an artifact of hand-picked separable rate constants — the γ-separability is an upper bound on real-world discriminability. This caveat is surfaced in the artifact, not buried.

4.15 · Reality check — blind external validation reality-check-1.0

The falsification test that de-circularises the whole engine (design §6C/C1): run PRISE blind on proteins the field considers mechanistically resolved and check its verdicts do not contradict published consensus. Five fixed points are pre-registered with citations (Aβ42 = secondary-nucleation, γ≈1.1, Cohen/Knowles PNAS 2013; Aβ40; α-synuclein, Buell PNAS 2014; insulin; β2-microglobulin). Because PRISE honestly refuses to name a mechanism, the correct test is non-contradiction: (1) modal regime must be cooperative/threshold; (2) γ within band where a strong consensus value exists; (3) the consensus mechanism must be a member of PRISE's equivalence class, not positively excluded.

Result — PRISE passes

5 / 5 fixed points CONSISTENT, 0 contradictions on the calibrated engine. Aβ42's PRISE γ = 1.18 falls inside the consensus band [0.8, 1.4] (γ≈1.1). Reserved-proteins/leakage discipline enforced (these 9 are used solely for this role). Honest framing: a thermometer against a few fixed points — not proof of correctness, not statistical calibration.

7Constraints & honest limitations

  • All calibration is synthetic. Service C, the conformal coverage guarantee and the applied thresholds are validated on synthetic ground truth under PRISE's own forward model. The blind reality check (§4.15) is the only external anchor, and it is a few-fixed-points non-contradiction test, not statistical validation on real data.
  • Mechanism is unlicensed corpus-wide (0/1,654). Correct, not a bug — CPAD lacks the agitation/seeding metadata the quiescent-vs-shaken branch requires.
  • Cross-modal effective \(n\) ≈ 20–22 proteins (predictor scores are per-protein constants), and the corpus is biased to famous amyloids with essentially no negative class — so no honest specificity estimate for a sequence→amyloid classifier is available.
  • Every kinetic value is a graph digitisation — elevated, correlated point-wise uncertainty on every curve; the wild bootstrap handles heteroscedasticity but not serial correlation, so per-curve CIs are lower bounds on width.
  • Corpus-scale global ODE fit is infeasible routinely (stiff-ODE cost); it is a build-time enrichment only.
  • Single dataset ≠ protein truth. A single censored curve can read gradual/non-cooperative while the protein's aggregate is cooperative — PRISE deliberately does not over-read one curve (demonstrated on Aβ42).
  • The product is a single-user local prototype — no deployment, concurrency, auth, persistence or export.

  1. More external fixed points + a real held-out real-corpus calibration. Expand the reality check beyond 5 proteins and add leave-one-study-out coverage checks on adequate-\(n\) strata — the single biggest trust upgrade.
  2. An external forward-model generator (coarse-grained KMC / Smoluchowski) so the de-circularisation measures degradation under a genuinely different physics, not just ODE-vs-closed-form.
  3. Make the ODE global fit tractable (surrogate/emulator or early-time linearised closed forms) so mechanism constraints are available corpus-wide, not just build-time.
  4. Productionise: FastAPI + a typed frontend, an async job queue for the heavy fits, containerise with engine_build_id-keyed caching, and a downloadable per-protein report — turning the prototype into a deployable tool.
  5. Run Zyggregator/CamSol from sequence to add the solubility endpoint and a generic-aggregation axis, enabling more sequence↔kinetics comparisons under endpoint matching.
